# AI-Based Detection of Cyber Threats in Unidirectional IP Traffic

## Project Overview

This project uses Artificial Intelligence and Machine Learning to detect and classify cyber threats from passively collected unidirectional IP traffic.

The system analyzes traffic features and identifies different types of network threats.

## Threats Detected

- NORMAL
- PORT SCAN
- BRUTE FORCE
- DOS
- DATA EXFILTRATION

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- FastAPI
- HTML
- CSS
- JavaScript

## System Architecture

Simulated IP Traffic
→ Feature Extraction
→ AI/ML Model
→ Threat Detection
→ Risk Assessment
→ Dashboard

## Features

- AI-based traffic classification
- Threat detection
- Confidence score
- Risk level
- Supporting evidence
- Monitoring dashboard
- Passive/unidirectional traffic monitoring concept

## Project Purpose

The system is designed for monitoring environments where traffic can be observed but the monitoring system cannot communicate back to the production network.

This prototype uses simulated traffic for safe testing and demonstration.
